
# Faze. - 自作グッズ販売ECサイト

~ My Face, Your Faze. ~  
私の顔で、あなたを動揺させる

---

## 開発背景

自作の商品を面白おかしく友達に届けるためにECサイトを自作しました。

初めてのアプリ作成はC++のMFCによるTODOリストでした。自分で使うには便利でしたが、WindowsのPCでしか動かない、共有が難しいといった制限があり、どうしても自分の中だけで完結してしまうもどかしさがありました。
その経験から、「せっかくアプリケーションを作るのなら様々な人に共有したい」と思い立ち、Webの学習をスタートしました。Udemyの「The Web Developer Bootcamp」を受講した後、初めてのWebアプリケーションとして作成したのがこのアプリです。

## 開発コンセプト

- **シンプルかつ安全に:** 初めてのWeb開発のため複雑なことには挑戦せず、極力シンプルな設計を心掛けました。また、セキュリティに明るくないため、ユーザーの個人情報は保存せず、個人情報の漏洩に配慮しました。
- **保守性の高い設計:** 責務がごちゃ混ぜにならないよう、`Router` / `Controller` / `Service` と層を分離し、ソースコードの見通しが良くなるよう意識して実装しました。
- **現実に即した設計:** 途中まではシステムとしての完成度を求め、在庫を抱える前提で作成していましたが、実際の運用では受注販売になることを考慮し、必要最低限で作成しました。また、決済方法についても一般的なStripeではなく、友人間の遊びであることを考慮し決済方法を工夫しました。

## 使用技術

- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** Passport.js
- **Template Engine:** EJS
- **Styling:** Bootstrap 5
- **Image Storage:** Cloudinary
- **Hosting / Deploy:** Render

## 主な機能

### ユーザー側
- **ユーザー登録・ログイン・ログアウト**
  - ユーザー名・メールアドレス・パスワードを入力しユーザー作成ができる
  - ログインはメールアドレスとパスワードで行う
- **商品閲覧・詳細表示**
  - 一覧画面から商品の詳細やバリエーション（サイズ等）の確認ができる
- **商品レビューの投稿**
  - 購入した商品のレビューの書き込みができる
- **カートへの追加**
  - 気になる商品をカートへ追加・数量変更・削除ができる
- **注文・購入フロー**
  - カート内容で注文の確定ができる
  - 注文内容や注文のステータス（現在の状況）の確認ができる

### 管理者側
*(ユーザー側で可能な機能に加え、以下の機能の利用権限が付与されます)*
- **商品・バリエーション管理**
  - 商品の新規登録、編集、削除ができる
  - 商品に対するバリエーション（サイズ）の管理
- **カテゴリー管理**
  - 商品カテゴリーの新規登録、編集、削除ができる
- **注文管理**
  - 注文一覧の表示ができる
  - 注文のステータスの変更ができる

## 開発時の苦労と学び

- **FilePondを用いた画像プレビューと並び替えの実装**
  - 画像のプレビュー表示と並び替えのロジックがうまくかみ合わず、UIの連結部分で苦戦しましたが、試行錯誤して何とか形にすることができました。
- **Variantモデル追加に伴う大規模な設計修正**
  - アプリがほぼ完成した段階で、商品のサイズなどのバリエーションを扱ううえでVariantモデルが必要だということに気が付きました。
  - Variantモデルを追加するうえで、商品、カート、注文モデル、それに伴うロジックの変更など、すでに完成したと思っていた部分の大幅な修正が必要となりました。
  - その経験から「あらかじめ全体の設計を見通していく力」の重要性を学びました。
- **複雑化へのアプローチ**
  - 商品登録時に同一画面でバリエーション登録もできたら便利だと考えましたが、今の自分の実力では複雑化してしまうと感じました。
  - それを実現しようと時間をかけすぎてしまいましたが、もっとシンプルに実装ができるということに気が付き、わざわざ複雑にせずシンプルに実装することを学びました。
  - 実装できないと思ったときは一歩引いてみて、もっとシンプルな方法はないのか？ということを考えることが重要だと感じました。
- **個人開発という難しさ**
  - 初めてのWebアプリということもあるかもしれないが、このレベル、この規模の実装だけでも約4か月の時間がかかりました。実装自体はそれほど難しくない機能でも、一人で作成しようとなるとかなりの時間がかかることを実感しました。
  - また、全て一人で考え作成したため、考慮しきれていない懸念点やバグがあるかもしれないと感じました（自分の未熟さもあるかもしれません）。
  - 有識者や他者を交えながら、一人では思いつけない懸念点などについて話し合う機会が、よりよいシステム作成には必要だと強く感じました。

## 今後の展望

現在は「友人間での手渡し・個人で運用する」ことを前提にシステムの仕様を決定しましたが、今後は以下の機能拡張を検討しています。

- **配送・決済方法の拡張**
  - 現在は手渡しを想定していますが、将来的には「手渡し / 発送」の選択機能や、それに伴う送料の自動計算ロジックの追加
  - 支払い方法について、現在の「PayPay IDでの個別送金」から、決済手段の選択肢を増やすこと
- **機能の充実**
  - 商品の検索機能や並び替え（ソート）機能、人気商品のレコメンド機能
  - ユーザー情報の編集・管理機能の追加

## ブランドコンセプト

"Faze." という名前は自作商品の「自分の顔のTシャツ」の "Face" と掛けて名づけました。  
このTシャツを着ているとすれ違う人に見られる、少し不思議そうな顔をされる、そんな経験から "Faze(動揺させる)" という意味で名づけました。  
また、商品自体がユニークなため、サイト自体はミニマルでモノトーンな落ち着いた雰囲気で作成しました。  
サイト自体のスタイリッシュさと商品のユニークさのギャップをお楽しみいただければ幸いです。
